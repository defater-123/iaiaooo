# 🌐 IP Checker Аддон

## 📝 Описание
Аддон для получения публичного IP адреса через разные сервисы.
Поддерживает проверку через HTTP, TCP и UDP.

## 📋 Команды

| Команда | Описание |
|---------|----------|
| `/ip` | Получить публичный IP |
| `/myip` | Детальная информация об IP |
| `/checkip` | Проверка IP + портов |

## 🔧 Методы

### `get_ip()`
Возвращает публичный IP адрес.
```python
from addons.ip_checker.main import get_ip
ip = get_ip()  # "123.45.67.89"
