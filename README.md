# VPS-github-shh

🌐 **VPS Manager** — красивый веб-сайт для управления серверами через GitHub Actions.
Без Telegram-бота: весь код бота удалён и полностью переделан в веб-панель.

## ✨ Возможности

| Раздел | Что умеет |
|---|---|
| 🔐 Авторизация | Код доступа из логов GitHub Actions → сессия на 6 часов |
| 📊 Дашборд | CPU, RAM, диск, uptime, ОС, IP, данные для SSH (с копированием) |
| 📁 Файлы | Полная файловая структура: просмотр, создание файлов/папок, встроенный редактор кода, удаление, скачивание, загрузка |
| 💻 Терминал | Выполнение команд на сервере с потоковым выводом в реальном времени (SSE), история команд (↑/↓) |
| 💾 Git-синхронизация | Сессии и изменённые файлы автоматически коммитятся в репозиторий |

## 📂 Структура проекта

```
.
├── .github/workflows/
│   ├── vps-web.yml        # 🚀 основной workflow: сервер + панель + туннель
│   └── vps-keepalive.yml  # 🔄 перезапуск с новым кодом
├── web/                   # сайт + API-сервер (без внешних зависимостей!)
│   ├── index.html         # интерфейс панели
│   ├── server.py          # HTTP-сервер: статика + JSON API + SSE
│   ├── css/style.css      # стили (тёмная тема GitHub Dark)
│   └── js/app.js          # клиентская логика
├── Saves/                 # данные сессий (синхронизируются с Git)
│   ├── sessions.json
│   └── tokens.json
└── README.md
```

## 🚀 Как использовать

1. Открой вкладку **Actions** в репозитории и запусти workflow **🚀 VPS Web Server**.
2. В логах запуска найди блок `✅ VPS WEB-ПАНЕЛЬ ГОТОВА`:
   - `🌍 САЙТ` — публичная ссылка на панель (cloudflared tunnel);
   - `🔑 КОД ДОСТУПА` — 8-значный код.
3. Открой ссылку в браузере, введи код — панель готова ✨

> Сервер живёт ~6 часов (пока работает Action). Для продления запусти
> **🔄 VPS Keep Alive** — он выдаст новый код и новую ссылку.

## 🛠 Локальный запуск

```bash
python3 web/server.py --port 8080                   # запустить панель
python3 web/server.py --add-code AB12CD34:IP:PASS   # зарегистрировать код
```

Зависимости: только стандартная библиотека Python 3 (`http.server`).
Никаких Flask / pip / Telegram — всё работает «из коробки» на раннере.

## 🔒 Безопасность

- Доступ только по одноразовому коду с временем жизни 10 минут;
- После активации выдаётся случайный Bearer-токен (сессия до 6 часов);
- Файловые операции ограничены корнем раннера (защита от path traversal);
- Кнопка «Отозвать доступ» мгновенно убивает сессию.
